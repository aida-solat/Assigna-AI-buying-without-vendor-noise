# PRD — Assigna: B2B Solution Assignment Engine

> Built & designed by Deciwa

خیلی خوب. ChatGPT یه PRD اولیه خوب داده. من الان نقش‌م اینه که اون رو **سخت‌تر، دقیق‌تر و buildable‌تر** کنم — چون اون PRD هنوز چند ambiguity داره که اگه حل نشن، توی code و architecture مشکل‌ساز میشن.

---

## نقد PRD فعلی ChatGPT

### ✅ چیزایی که solid هستن:

- **Product thesis** واضحه: Buyer problem → Need diagnosis → Vendor assignment → Decision brief
- **Core objects** درست define شدن (BuyerProblem, NeedObject, VendorProfile, AssignmentDecision)
- **"Payment must not change ranking"** — golden rule
- **Scoring formula** ساده ولی explainable

### 🔴 چیزایی که هنوز ambiguous یا ضعیفن:

**1. "Need Diagnosis" جادویی‌ترین بخشه ولی کمترین جزئیات رو داره**

> سیستم تشخیص میده مشکل واقعی چیه

ولی **چطور؟** اگه LLM-only باشه → unreliable. اگه rule-based-only باشه → inflexible.

**باید مشخص بشه:**

- آیا diagnosis از taxonomy ثابت انتخاب میشه؟
- آیا LLM classify میکنه و بعد rule-based score میده؟
- Industry Playbook دقیقاً چه structure‌ای داره؟

**2. VendorProfile از کجا میاد؟**

PRD گفته "manual/curated" — ولی:

- کی curate میکنه؟
- Vendor خودش sign up میکنه؟ (marketplace model)
- یا Assigna team curate میکنه؟ (editorial model)
- یا both؟

این تصمیم **مدل کسب‌و‌کار** رو عوض میکنه.

**3. Evidence Quality Scoring خیلی important‌ه ولی spec نداره**

فقط گفته "verified customer reference = high". ولی:

- چطور verify میشه؟
- Self-declared evidence قبوله؟
- آیا Assigna خودش audit میکنه؟

**4. "Free diagnosis" چقدر value داره؟**

اگه free tier فقط بگه "تو document automation لازم داری" — ChatGPT هم اینو میگه. پس **paid value** باید خیلی واضح‌تر از diagnosis عمومی باشه.

## PRD v0.1 Refined — My Version

### 1. Product Thesis (Locked)

> **Assigna converts ambiguous B2B business problems into structured, evidence-scored vendor assignments with explainable decision reasoning.**

Key constraint:

- Buyer-first
- Evidence > Claims
- Reasoning > Scores
- Outcomes feed back into quality

### 5. Decision: Editorial Model First

**V0.1 = Curated by Assigna team:**

- 30-50 vendors manually profiled
- Evidence items verified by team
- Categories from fixed taxonomy

**V0.2 = Vendor self-registration:**

- Vendor creates profile
- Claims verified by Assigna
- Unverified evidence clearly marked

**V1.0 = Full marketplace:**

- Vendor pays for presence (not rank)
- Buyer-initiated RFP-like flow
- Outcome tracking

### 6. Value Chain: Free vs Paid

| Tier           | What buyer gets                                                             | Price           |
| -------------- | --------------------------------------------------------------------------- | --------------- |
| **Free**       | Problem intake + category diagnosis ("You need X, not Y")                   | €0              |
| **Starter**    | Category + 3 vendor names (no reasoning)                                    | €99             |
| **Pro**        | Full Decision Brief (5 vendors, scored, reasoned, compared, with questions) | €499            |
| **Enterprise** | Multi-problem, ongoing vendor monitoring, custom playbook                   | €1,500-5,000/mo |

**Key:** Free tier must still be useful enough to demonstrate the diagnosis quality. It's the trust builder.

---

### 7. Risks Acknowledged

| Risk                   | Mitigation                                                        |
| ---------------------- | ----------------------------------------------------------------- |
| "ChatGPT does this"    | Structured output + evidence-scored + auditable + vendor-specific |
| Buyer won't pay        | Validate with 10 manual briefs first                              |
| Vendor DB too thin     | Start curated in 1 niche, expand with vendor self-registration    |
| Diagnosis wrong        | Confidence scores + human review for low-confidence cases         |
| Overly consulting-like | Automation pipeline from day 1, manual only where LLM can't       |
